スワイプキューブ　配布用ファイル一式
=====================================

■ 中身
  index.html             アプリ本体
  three.min.js           3D表示ライブラリ（同梱しているのでネットなしでも動きます）
  manifest.webmanifest   アプリ名・アイコン・全画面表示の設定
  sw.js                  オフライン起動用（一度開けば電波がなくても遊べます）
  icons/                 ホーム画面用アイコン（iPhone用180px、Android用192/512px、元画像1024px）

■ 配布のしかた（Webに置く）
  このフォルダを「https」のWebサーバーに置くと、URLを知っている人なら誰でも
  ホーム画面に追加して使えます。無料で置ける代表的な方法は次の2つです。

  A) GitHub Pages
     1. GitHubで新しいリポジトリを作る（公開設定: Public）
     2. このフォルダの中身をすべてアップロード（index.html が一番上に来るように）
     3. リポジトリの Settings → Pages で、ブランチ main / フォルダ root を選んで保存
     4. 数分後に表示される https://ユーザー名.github.io/リポジトリ名/ が配布URL

  B) Netlify
     1. Netlifyにログインし、新しいサイトを「手動デプロイ（ドラッグ＆ドロップ）」で作る
     2. このフォルダをそのままドラッグ
     3. 発行された https://〇〇.netlify.app が配布URL

  ※ ファイルをパソコンで直接ダブルクリックして開いただけでは、
     オフライン機能とホーム画面アイコンは働きません（httpsが必要です）。

■ iPhoneでホーム画面に追加する
  1. Safariで配布URLを開く
  2. 下の共有ボタン（□に↑）をタップ
  3. 「ホーム画面に追加」→「追加」
  → キューブのアイコンが並び、タップするとブラウザの枠なしの全画面アプリとして起動します。

■ Androidの場合
  Chromeで配布URLを開き、メニュー（︙）→「ホーム画面に追加」または「アプリをインストール」。

■ 更新したいとき
  ファイルを差し替えたら、sw.js 1行目付近の CACHE = 'swipecube-v1' の数字を
  v2, v3… と上げてください。上げないと、すでに入れた人の端末に古い版が残ります。

■ ベスト記録について
  記録はそれぞれの端末の中だけに保存されます。
